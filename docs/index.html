🎧 Genre Sorter

Sort your Liked Songs by genre

Turns your Liked Songs into tidy playlists like Hip-Hop & Rap, Indie & Alternative and Latin. You'll see a preview before anything is created.

  • Nothing is installed. Your music data stays in this browser.
  • Run it again any time. The same playlists get updated, never duplicated.
  • It only creates and updates its own playlists. It never changes your Liked Songs.

Set up your free Spotify app

Spotify asks everyone who uses a tool like this to create a free "developer app" first. It's a form with five boxes, and this guide walks you through each one. About 3 minutes.

  • You'll need Spotify Premium. Spotify requires it for apps like this.
  • You don't need to know anything about coding. You'll only click, copy and paste.
  • Keep this page open. Spotify's site opens in a new tab, and you'll come back here.

First: open Spotify's developer site

Open Spotify for Developers ↗

Log in with your normal Spotify account. If Spotify asks you to accept its developer terms or to verify your email address, do that first, then come back to this tab.

Create the app

On Spotify's page, click Create app (top right). A form opens. Fill it in using the buttons below.

  1. App name:
    Genre Sorter
  2. App description:
    Sorts my Liked Songs into genre playlists
  3. Redirect URIs: paste this, then click Add next to the box. This is the step people miss most.
  4. Under Which API/SDKs are you planning to use?, tick Web API.
  5. Tick the box agreeing to Spotify's terms, then click Save.

Copy your Client ID

After saving, Spotify shows your new app's page. Click Settings (top right of that page).

Copy the Client ID. Don't use the Client secret; this app never needs it.

Log in and allow access

Spotify will ask whether Genre Sorter may see your Liked Songs and make playlists. Click Agree.

Spotify showed an error instead?
"INVALID_CLIENT: Invalid redirect URI"
The Redirect URI wasn't added. In your app's Settings, click Edit, paste the Redirect URI from step 2, click Add, then Save at the bottom. Then try again.
"INVALID_CLIENT: Invalid client"
The Client ID is wrong, or it's the Client secret. and copy the Client ID again.
"Something went wrong" or a blank page
Wait a minute (a new app can take a moment to start working), then try again.
It says you're not allowed, or Premium is needed
Log in with the same Spotify account you used to create the app, and make sure it has Premium.

      Last setup step

      Get a free Groq key

      Groq is a free AI service that works out each song's genre. It needs a "key", a password-like code that lets this page use your free allowance. About 1 minute, no credit card.

      1. Open Groq's keys page and sign in. Signing in with Google or GitHub is fine.
        Open Groq keys page ↗
      2. Click Create API Key. Type any name (for example Genre Sorter) and confirm.
      3. Click Copy next to the key Groq shows. Groq only shows it once, so copy it before closing that window.
      4. Paste it here:

      Lost the key or closed the window too soon? Just create another one; it's free. Only song titles and artist names are sent to Groq. Your key stays in this browser and is only ever sent to Groq.

      Groq's free allowance is used up for today

      Everything sorted so far is saved.

      Groq may still have some left. This limit is the app's own cautious count of today's usage, not Groq's. Checking costs nothing: if Groq really is out, it says exactly when it resets.

      Or continue now with another model. Each Groq model has its own free daily allowance. Smaller models know fewer songs, so they're less accurate. Your usual model takes over again once its allowance resets.

      Or make playlists now with what's sorted. Unsorted songs are kept aside, not put in the wrong playlist, and the next run adds them to the same playlists. Nothing is duplicated.
